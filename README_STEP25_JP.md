# shattered_crown_echo STEP 25 — 決着技カットイン表示改善

## 対象
STEP 24 の Web Solo 試作版をベースにした **Godotプロジェクト一式**です。

## 変更点
- 決着技用素材 `ui_trial/assets/cutin_temp.webp` を、文字を含まない新しいイラスト領域へ差し替え（新規作成したコンセプト画像から画像の人物領域のみ抽出）
- `ui_trial/battle_ui_step9.gd` のカットイン表示を変更：戦闘フィールド領域内のパネルに収め、左に人物、右に `FINISHER`・武器種・決着技・属性を表示
- デバッグID `C012` などをカットイン演出に出さない
- 表示時間は約1.19秒（演出速度=1.0の場合）
- 通常Attack・Block・Skillは前回どおりカットインなし
- Battle Core / カードデータ / HP / Mana / 敵AI / セーブデータ / オンライン協力処理には変更なし

## Godot 4 での確認
1. ZIPを別のフォルダに解凍する。
2. `project.godot` をGodotからインポートする。
3. 左下の `ui_trial/battle_ui_step21_lab.tscn` をダブルクリックして F6 で実行する。
4. R1-B01に通常攻撃を行う。カットインが出ず攻撃モーションが再生されること。
5. C012（物理・刀・決着技）を使う。戦闘フィールド内に1回だけ新しいカットインが表示されること。
6. 人物の顔に文字が重ならず、HP・Mana・手札領域を覆わないこと。

## 注意
- 完成したWindows版・EOS協力版ではなく、Web Soloベースの試作環境です。
- Godot 4.7.2での実機起動試験はこの制作環境では未実施です。静的検査・ZIP整合性のみ確認しています。
- カードマスターの120枚には個別の正式技名フィールドがないため、カットインには「刀・決着技」のように武器種と役割を表示します。将来、正式名称フィールドが追加された際に変更可能です。
- イラストはゲーム完成版の専用人物アートではなく、試験用の文字なし専用切り出し画像です。
